# Arigato Sushi Website 🍣

A customer-facing website developed for Arigato Sushi, a sushi restaurant in London.

## Features

- Restaurant information
- Sushi menu
- Customer ordering
- Order details
- Customer information
- Responsive website design

## Technologies

- HTML
- CSS
- JavaScript

## Live Website

https://arigato-sushi.netlify.app/

## Purpose

This website was developed for Arigato Sushi to provide customers with an online presence and a simple way to view the menu and place orders.
